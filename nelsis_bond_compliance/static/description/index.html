Nelsis Bond Compliance

Module 01 of Nelsis Bond Warehouse — version-controlled regulatory rule register for Bangladesh bonded warehouses (leather, footwear, leather goods).

  • Rule register with official reference, source URL, publication and effective dates
  • Explicit license / factory category applicability (never assumed)
  • Required documents and validation parameters (no statutory values pre-filled)
  • Review → approval → activation workflow with segregation of duties
  • Rule versions, supersession, immutable evaluation log
  • Compliance exceptions with approval and expiry
  • Evaluation interface bond.compliance.engine for other modules
